# BESMA 최종 메뉴트리 확정본 (Depth 1~3)

- **고정**: 병합/분리/추가/삭제/명칭변경 금지.
- **고도화**: 기본 메뉴트리에 섞지 않고, 고도화 섹션으로만 분리 표기.

---

## 고정 운영 원칙

| 항목 | 내용 |
|------|------|
| 예산 | 본사 편성/통제. 현장은 **당 현장 사용실적 입력·조회만**. |
| 네이버웍스 | 예산 품의 연동은 **메일 제목(Subject) 수집만**(본문/첨부/결재선 연동 금지). |
| 앱 | **2종**: 근로자용 / 관리자용. 근로자 홈: ‘작업중지’·‘위험요인신고’ **서로 다른 별도 버튼**. 관리자용은 위험요인신고/작업중지권이 홈에 직접 노출되지 않고 메뉴 진입 후 사용. |
| GPS | 가변 주기(정지/이동/Geofence/이벤트) + 저장 **3개월 일반 / 5년 압축 보관**. |

## Role 용어 고정

- **문서/화면**: HQ_ADMIN / SITE_ADMIN / WORKER
- **코드 라우팅(roleCategory)**: hq-admin / site-admin / mobile (기존 유지)
- **WORKER = mobile** (다이어그램·설명에서는 “mobile” 표기 금지, “근로자” 사용)

---

## 1. 근로자 앱 (WORKER APP)

- **홈**
  - 작업중지(SOS) 버튼 (홈 즉시 노출)
  - 위험요인신고 버튼 (홈 즉시 노출)
  - 오늘 작업요약(금일 작업지시 상태)
- **작업**
  - 금일 작업지시
    - 작업지시 상세(위험요인/대책 확인 + 서명)
    - 작업 시작(증빙용)
    - 작업 종료(서명 + 사진 업로드)
  - 작업이력: 일자별 작업지시/서명/사진 기록
- **안전활동**
  - 위험요인 신고: 입력(음성/촬영 + 텍스트), 아차사고 전환(체크박스), 신고이력
  - TBM(자동생성/서명연동): 금일 TBM 확인, 서명 이력
- **증빙/내정보**
  - 이수증/자격: 이수증 등록/조회(기본). ※ QR은 옵션(기본 메뉴에 QR 배치 금지)
  - 내 위치기록(조회): 최근 3개월 조회(기본)
- **설정**: 알림/권한, 로그아웃

---

## 2. 관리자 앱 (ADMIN APP)

- **홈(관리업무 중심)**: 현장 선택, 오늘 현장 요약, 빠른메뉴(작업관리/안전관리/문서/예산)
- **작업관리**
  - 작업지시(관리자용): 작업지시 생성/배포, 현황, 개인별 서명 확인
  - 작업일보(명일): 작성, 제출/공유
- **안전관리**
  - 의견청취관리대장(=위험신고처리): 신고 목록/상태, 1차/2차 점수 입력
  - 작업중지권(SOS) 목록: 접수/조치상태 기록
  - 점검/시정조치: 점검표 업로드/조회, 시정조치보고서(PDF 출력/저장/열람)
- **문서함**: 법정서류 업로드/조회, OCR 입력(옵션)
- **예산(현장 입력 범위)**: 사용실적 입력, 사용현황 조회
- **연락/비상**: 비상연락망(전화걸기), 비상대응카드(열람)
- **설정**: 알림/권한, 로그아웃

---

## 3. 현장 관리자 웹 (SITE WEB)

- **대시보드**: 오늘 작업 진행률(공정표 표출 연계), 미확인/미서명/지연 알림
- **작업관리**
  - 작업일보(명일): 작성/제출/승인(소장 승인 포함)
  - 작업지시: 목록/상세, 개인별 확인(서명) 상태, 종료(서명+사진) 상태 조회
  - 작업이력: 기간/인원 필터 조회
- **안전관리**
  - 위험성평가: 현장 위험성평가 작성/조회, 표준 항목 참조(본사 표준DB 기반)
  - TBM: TBM 일지(작업지시/서명 자동연동), 중점위험 교육 항목 포함, 출력(PDF/엑셀)
  - 의견청취관리대장: 신고 목록/처리(현장 1차), 음성=로컬 STT 텍스트만 저장(권장)
  - 점검: 순회점검표·관리감독자 점검표 업로드/조회
  - 시정조치보고서: 등록/열람, PDF 출력/서버 저장
- **문서함**: 법정서류 업로드/조회, 교육/자격 서류 관리(OCR 옵션)
- **예산(현장 범위)**: 사용실적 입력, 사용현황 조회
- **인력/조직**: 사용자/권한(현장 내), 팀/작업자 현황
- **설정**: 현장정보, 알림 설정

**현장 웹에서 제거/금지**

- 작업 완료 사진 승인/반려(숨김 또는 미구현)
- 작업관리 “승인/반려” 버튼(표시 금지)

## 4. 본사 관리자 웹 (HQ WEB)

- **통합관제**: 전국 현장 지도(핀·SOS/긴급 강조), 현장 목록(상태·담당자 지정현황)
- **KPI**: 현장 KPI 대시보드, 등급/점수 집계
- **표준 위험성평가 DB**: 표준 공종/위험요인/대책 관리, 현장 적용 템플릿 관리
- **결재/승인**: 문서·사고보고서·기안/보고 결재(권한별)
- **통계**: 의견청취, 점검/시정조치 통계, 작업지시/서명 준수율
- **시스템 관리**: 계정/권한(RBAC), 현장 개설/준공/데이터 이관, 알림/푸시 정책
- **예산(본사 고유)**: 예산 편성/통제, 예산 집행 현황(현장 입력 취합), 네이버웍스 품의 목록(메일 Subject 수집 기반)

## 고도화 섹션 (기본 메뉴트리에 섞지 말 것)

- **고도화-비상 대응 플랫폼**: 비상대응조직도, 비상연락망, 비상대응훈련/카드, 전원 경고·집결지 도면, CPR 순서도
- **고도화-품질 점검(공사팀)**: 품질점검 체크리스트, 시정조치요구서·개선조치보고서, 승인 역할, 월 보고 PDF
- **고도화-평가/성과 연계**: 업무분장표 → 성과평가 → 안전관계자평가 연계
- **고도화-다국어/알림/검색**: Papago, SENS(비상만), 검색 로그 분석
