## 2. 각 박스 설명 (역할 / 데이터 / 권한)

| 요소 | 역할 | 데이터 | 권한 |
|------|------|--------|------|
| **본사 웹** | 통합관제·KPI 조회·설정. 시정조치 배정·열람. **예산 편성/통제.** | 통합관제·KPI·시정조치·**예산 편성 데이터**. | 전체 현장 모니터링, 표준 DB 관리, 결재 승인, 통계 열람, **예산 편성·통제.** |
| **클라우드 서버** | 사용자관리, 작업지시·위험성평가·TBM·의견청취·기능인 등급·**GPS 로그(가변 주기, 3개월 일반+5년 압축)**·서류/OCR. 네이버웍스 **메일 제목(Subject) 수집**. | 동일. | 본사 웹·현장 웹·근로자 앱·관리자 앱에 API로 데이터 제공. |
| **현장 관리자** | 작업지시 생성·발행, TBM 작성, 점검 관리, 작업자 관리. **예산 사용실적 입력·조회만.** | 작업지시 생성 입력, TBM 입력, 점검 입력, **사용실적 입력**. | 소속 현장 데이터 관리, 작업지시 발행, TBM 작성, 위험성평가 등록. **예산: 사용실적 입력/조회만.** |
| **근로자 앱** | 작업지시 확인·전자서명, 작업완료·전자서명. **홈에 ‘위험요인신고’·‘작업중지’ 별도 버튼.** | 작업지시 수신·확인·서명·완료 서명. GPS(가변 주기, 3개월 일반+5년 압축). | 작업지시 수신, 전자서명, 안전활동 참여, 위험요인신고·작업중지 버튼. |

- **데이터 흐름**: 본사 웹 → 클라우드 서버(조회/설정·예산 편성). 현장 관리자 → 클라우드 서버(작업지시 생성, TBM, **사용실적 입력**). 클라우드 서버 → 근로자 앱(작업지시 배포). 근로자 앱 → 클라우드 서버(확인/서명, 완료 서명, **GPS 가변 주기 저장**, 위험요인신고·작업중지).
- **시정조치**: 본사 웹 전용. 현장 웹에는 시정조치 기능 배치하지 않음.
- **앱**: 근로자용 앱 / 관리자용 앱 2종. 근로자 홈에는 ‘위험요인신고’와 ‘작업중지’가 별도 버튼으로 존재.

## 3. 데이터 흐름 단계 설명

### 1단계: 본사 → 클라우드 서버

- 본사 웹이 클라우드 서버에 접속하여 통합관제·KPI 데이터를 조회한다.
- 본사 웹이 표준 위험성평가 DB·시스템 설정·결재/승인·시정조치·**예산 편성/통제** 등을 서버에 반영·조회한다.

### 2단계: 현장 관리자 → 클라우드 서버

- 현장 관리자가 작업지시를 생성·발행하면 클라우드 서버의 작업지시 DB에 저장된다.
- TBM 입력은 클라우드 서버의 TBM DB와 자동 연동된다.
- 무사고일지와 연동된다(무사고일지 연동).
- 예산은 본사 편성/통제이며, 현장은 **사용실적 입력·조회만** 가능하다.

### 3단계: 클라우드 서버 ↔ 근로자 앱

- 클라우드 서버가 작업지시를 근로자 앱에 배포한다.
- 근로자가 작업지시 확인 후 서명 방식으로 확인한다.
- 근로자가 작업완료 시 서명 방식으로 보고한다.
- GPS는 가변 주기(정지/이동/지오펜스/이벤트)로 수집되며, 저장은 3개월 일반 보관 + 5년 압축 보관이다.

## 4. API 사용 구간 구분

| 구간 | API/기술 | 용도 | 구분 |
|------|----------|------|------|
| 근로자 앱 음성 입력 | Web Speech API | 로컬 STT. 음성 → 텍스트 변환 후 텍스트만 서버 전송. | 로컬(클라이언트). |
| 서류 인식 | CLOVA OCR | 서류 이미지 → 텍스트 추출(선택 호출). | 선택 호출. |
| 번역 | Papago | 텍스트 번역(선택 호출). | 선택 호출. |
| 비상 알림 | SENS | 비상용 알림 발송. | 비상용만. |
| 지도 | — | 마지막 저장 위치만 표시. 강제 푸시 시에만 위치 업데이트. | 규칙 준수. |
| 네이버웍스 | — | **메일 제목(Subject) 수집**만. | 연동 범위 고정. |
| GPS 로그 | — | **가변 주기**(정지/이동/지오펜스/이벤트). **저장: 3개월 일반 + 5년 압축 보관.** | 서버 저장 규칙. |

- 음성: Web Speech API로 로컬 STT 후 텍스트만 서버 저장.
- 지도: 마지막 저장 위치만 표시하며, 강제 푸시 시에만 업데이트.
- GPS: 가변 주기 수집, 3개월 일반 보관 + 5년 압축 보관.

## 5. 1단계 / 2단계 / 3단계 기능 분리

### 1단계 기능 (본사 웹 ↔ 클라우드 서버)

- **통합관제 대시보드** (MUST): 전사 현장·KPI·알림 조회.
- **KPI 관리** (MUST): 지표 정의·목표·실적·리포트.
- **표준 위험성평가 DB 관리** (MUST): 표준 DB 정의·버전·배포.
- **결재/승인** (MUST): 전사 결재함·승인·반려.
- **통계 분석** (MUST): 사고·교육·점검 등 통계·리포트.
- **시스템 설정** (MUST): 조직·권한·계정·정책.
- **시정조치** (MUST): 본사만. 시정조치 배정·열람·처리.
- **예산** (MUST): 본사 편성/통제. 현장에는 편성·통제 기능 배치하지 않음.

### 2단계 기능 (현장 관리자 ↔ 클라우드 서버)

- **작업지시 생성** (MUST): 작업지시 작성·발행 → 작업지시 DB 저장.
- **TBM 자동연동** (MUST): TBM 입력 → TBM DB 연동.
- **무사고일지 연동** (MUST): 무사고일지와 연동.
- **작업관리/점검** (MUST): 점검·작업자 관리 등 현장 관리자 기능.
- **예산** (MUST): 현장은 **사용실적 입력·조회만** 가능. 편성/통제는 본사만.

### 3단계 기능 (근로자 앱 ↔ 클라우드 서버)

- **작업지시 확인(서명)** (MUST): 서명 방식으로 확인.
- **작업완료(서명)** (MUST): 서명 방식으로 완료 보고.
- **GPS** (MUST): 가변 주기(정지/이동/지오펜스/이벤트) 수집. 저장: 3개월 일반 + 5년 압축 보관.
- **ERP → 개인별 작업지시 자동 생성** (MUST): ERP 연동 시 작업지시 자동 생성.
- **의견청취 1차/2차 점수 반영** (MUST): 의견청취 관리대장 반영.
- **기능인 등급 S/A/B/C** (MUST): 기능인 등급제 반영.
- **SOS → 본사 지도 Red 깜빡임** (MUST): 비상 시 본사 지도에 Red 깜빡임.
- **오프라인 저장 → 통신 복구 시 동기화** (MUST): 오프라인 데이터 복구 시 동기화.
